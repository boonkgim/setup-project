Added to `SLICE.md`:

- **The `devEngines` trap is root-init-only.** `pnpm init` writes the block only when it finds
  no workspace root above it — verified both ways on pnpm 11.15.1, in a directory under an
  existing workspace's `packages/` (no block) and outside any workspace (block). The later
  sub-package inits were already right to omit the deletion step; now the slice says why.
- **`pnpm verify` cannot run before a repo's first commit.** Both `format:changed` and turbo's
  `--filter="...[HEAD]"` resolve `HEAD`, and a repo with no commits has none, so both fail with
  `fatal: ambiguous argument 'HEAD'`. The gate has to be passable before the commit it gates,
  which is why `verify` is not one of its rows. Documented together with formatting the
  root-level files directly that one time, since `pnpm format` only fans out to packages.
- **`git init` and a check of what `git add -A` stages**, at the commit step. A tooling
  directory symlinked in from elsewhere on the machine is stored by git as its target string
  (mode `120000`), which writes one machine's absolute layout into the repo and hands every
  other clone a dangling link. Ignore such a path rather than commit it.
